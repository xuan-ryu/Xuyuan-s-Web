Motion

Choreography, not decoration.

Scroll scenes can stay cinematic. Ordinary UI should be short and tactile, mostly transform and opacity. The motion language should not introduce color or layout noise.

Implementation rule

Keep heavy motion isolated.

  • Hero, roof, windows, koi, and Hongyadong scenes can own their choreography.
  • Reusable UI uses `--ease-silk` and small transform changes.
  • Reduced-motion fallback is required for any touched scene.
